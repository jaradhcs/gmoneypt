# TradeMarked Co. Website

This repo contains a simple Node.js website demonstrating a modern dark theme and a basic chatbot powered by the OpenAI API.

## Setup

1. Install dependencies
   ```bash
   npm install
   ```
2. Create a `.env` file with your OpenAI API key:
   ```
   OPENAI_API_KEY=your-key-here
   ```
3. Start the server
   ```bash
   npm start
   ```

The site will be available at `http://localhost:3000`.

## Features

- Dark theme with glassmorphism effects
- Example pages: services, pricing, case studies
- Simple chat widget that calls the OpenAI API

Use this project as a starting point for building a full-featured platform.
